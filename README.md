# Vault — мультичейн крипто-кошелёк

Веб-кошелёк в духе Trust Wallet: один seed (12 слов) → адреса в нескольких сетях,
курсы валют, добавление токенов, обмен, покупка за карту и тестовая сеть для
безопасной проверки переводов. Приватные ключи и seed хранятся и используются
**только в браузере** — никуда не отправляются.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`).

Для продакшен-сборки:
```bash
npm run build
npm run preview
```

## Тестирование переводов без риска

Не используйте никакую «известную всем» seed-фразу на основной сети — если на
неё случайно попадут реальные деньги, их заберут (фраза публичная, кошелёк не
защищён). Вместо этого:

1. Настройки (⚙) → включите **«Тестовая сеть»**.
2. Откройте актив (Ethereum Sepolia, BNB Testnet или Bitcoin Testnet) →
   кнопка **«Получить бесплатные тестовые монеты»** на его карточке ведёт на
   кран (faucet) — монеты бесплатные, ничего не стоят.
3. Проверяйте отправку/получение как обычно — сеть отдельная от mainnet,
   комиссии и балансы настоящие, но без реальной цены.

Своп и покупка за карту в тестовой сети отключены — у агрегатора и провайдеров
нет тестовой ликвидности/окружения, доступных без отдельной интеграции.

## Что поддерживается

- **Сети:** Ethereum, BNB Smart Chain, Polygon, Arbitrum One, Optimism, Base,
  Avalanche (все EVM — один и тот же адрес), плюс Bitcoin. Тестовые сети:
  Ethereum Sepolia, BNB Testnet, Bitcoin Testnet.
- **Создание и импорт** кошелька по BIP-39 seed-фразе (12 слов).
- **Биометрическая разблокировка** — отпечаток/Face ID через WebAuthn + PRF.
- **Курсы и графики** — цена, изменение за 24ч, 7-дневный спарклайн (CoinGecko).
- **Добавление токенов** — поиск по названию/тикеру сразу по всем сетям
  (реестр 1inch) или вручную по адресу контракта.
- **Обмен (Swap)** — котировки и сама транзакция через открытый агрегатор
  ParaSwap, без API-ключа.
- **Покупка (Buy)** — по умолчанию без какой-либо регистрации: показывает
  адрес/QR и ссылки на обычные биржи (Binance, Coinbase, Kraken) — купить там
  как рядовой клиент и перевести на свой адрес, никакого партнёрства с нашей
  стороны. Есть свёрнутый «продвинутый» вариант (доставка сразу на адрес через
  MoonPay/Transak) — он требует регистрации партнёра, потому что приём оплаты
  картой регулируется как финансовая деятельность у любого провайдера без
  исключений.
- **Отправка:** нативная монета и ERC-20-токены на EVM; полноценная сборка и
  подпись Bitcoin-транзакции для BTC (mainnet и testnet).
- **Хранение:** seed-фраза шифруется паролем (AES-GCM + PBKDF2) в `localStorage`.

## Известные и исправленные баги

- **[Исправлено] Крах вкладки «Обмен» при успешном ответе сети.**
  `getEvmBalance` возвращал строку вместо числа (`ethers.formatEther` без
  `Number(...)`), из-за чего `.toFixed()` в SwapView бросал исключение —
  но только когда RPC-запрос реально успевал ответить (поэтому не проявлялось
  при тестировании в песочнице без сетевого доступа). Исправлено во всех
  местах с тем же паттерном (`walletCore.js`, `tokens.js`).

## Чего нет (и на что обратить внимание перед реальным использованием)

- **Нет истории транзакций** — только ссылка на блокэксплорер.
- **RPC/API — публичные и бесплатные.** Для продакшена лучше использовать
  платных провайдеров (Alchemy, Infura, QuickNode).
- **Нет аудита безопасности.** Обязателен перед тем, как доверять реальные
  деньги.
- **Своп не тестировался с реальным исполнением** — код написан по
  документированному контракту API ParaSwap, но сначала проверьте на малой
  сумме.
- **Нет проверки чексуммы/фишинговых адресов**, нет ENS.
- **localStorage** уязвим к XSS.

## Структура проекта

```
src/
  lib/
    chains.js       — конфигурация сетей (mainnet + testnet)
    tokens.js        — ERC-20: баланс, инфо, отправка, цена по адресу
    tokenList.js       — поиск токенов по названию/тикеру (реестр 1inch)
    prices.js            — курсы + спарклайн для нативных монет (CoinGecko)
    swap.js                — котировки и обмен через ParaSwap
    onramp.js                — конфиг и URL для покупки за карту (MoonPay)
    biometric.js               — WebAuthn/PRF биометрическая разблокировка
    crypto.js                   — шифрование seed-фразы (Web Crypto)
    storage.js                    — localStorage: vault, токены, testnet-флаг
    walletCore.js                   — деривация ключей, транзакции EVM/BTC
  components/
    Onboarding, BackupSeed, SetPassword, Unlock  — вход и первый запуск
    Dashboard, AssetDetail, AddAssetSheet          — список активов и детали
    SendSheet, ReceiveSheet, Sparkline               — переводы и графики
    SwapView, BuyView, BottomNav                       — обмен, покупка, навигация
    SettingsSheet, Toast                                 — настройки и уведомления
```
