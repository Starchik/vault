# Vault — мультичейн крипто-кошелёк

Веб-кошелёк в духе Trust Wallet: один seed (12 слов) → адреса в нескольких сетях,
курсы валют, добавление токенов, обмен и покупка за карту. Приватные ключи и seed
хранятся и используются **только в браузере** — никуда не отправляются.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`).

Для продакшен-сборки:
```bash
npm run build
npm run preview
```

## Что поддерживается

- **Сети:** Ethereum, BNB Smart Chain, Polygon, Arbitrum One, Optimism, Base,
  Avalanche (все EVM — один и тот же адрес), плюс Bitcoin (native SegWit / bech32).
- **Создание и импорт** кошелька по BIP-39 seed-фразе (12 слов).
- **Биометрическая разблокировка** — отпечаток/Face ID через WebAuthn + PRF
  (когда поддерживается устройством/браузером), с паролем как запасным вариантом.
- **Курсы и графики** — цена, изменение за 24ч, 7-дневный спарклайн (CoinGecko).
- **Добавление токенов** — поиск по названию/тикеру сразу по всем сетям (реестр
  1inch, без API-ключа) или вручную по адресу контракта.
- **Обмен (Swap)** — котировки и сама транзакция через открытый агрегатор
  ParaSwap (`apiv5.paraswap.io`), без API-ключа. Подписывается локально тем же
  приватным ключом, что и обычные транзакции.
- **Покупка за карту (Buy)** — заготовка под MoonPay/Transak. Без собственного
  API-ключа кнопка неактивна и показывает, где его получить — кошелёк сам
  платежи не обрабатывает, это всегда лицензированный партнёр.
- **Отправка:** нативная монета и ERC-20-токены на EVM; полноценная сборка и
  подпись Bitcoin-транзакции (UTXO, сдача, комиссия по sat/vB) для BTC.
- **Хранение:** seed-фраза шифруется паролем (AES-GCM + PBKDF2, 250k итераций) в
  `localStorage`.

## Чтобы включить покупку за карту

1. Зарегистрируйтесь как бизнес на [dashboard.moonpay.com](https://dashboard.moonpay.com)
   или [dashboard.transak.com](https://dashboard.transak.com) — получение
   публичного ключа бесплатно.
2. Вставьте ключ в `src/lib/onramp.js` (`moonpayApiKey` или `transakApiKey`).
3. Пересоберите — кнопка «Купить» на вкладке Buy станет активной.

Полноценный запуск платежей (не просто открытие виджета) также потребует
верификации бизнеса у провайдера — это отдельный процесс на их стороне.

## Чего нет (и на что обратить внимание перед реальным использованием)

- **Нет истории транзакций** — только ссылка на блокэксплорер.
- **RPC/API — публичные и бесплатные.** Для продакшена лучше использовать
  платных провайдеров (Alchemy, Infura, QuickNode) со своими ключами.
- **Нет аудита безопасности.** Обязателен перед тем, как доверять реальные
  деньги — особенно учитывая, что теперь кошелёк подписывает произвольные
  транзакции обмена от стороннего агрегатора.
- **Своп не тестировался с реальным исполнением** (агрегатор ParaSwap — код
  написан по документированному контракту API, но живой перевод средств стоит
  сначала проверить на малой сумме).
- **Нет проверки чексуммы/фишинговых адресов**, нет ENS.
- **localStorage** уязвим к XSS (см. предыдущие версии README для деталей).

## Структура проекта

```
src/
  lib/
    chains.js       — конфигурация сетей
    tokens.js        — ERC-20: баланс, инфо, отправка, цена по адресу
    tokenList.js       — поиск токенов по названию/тикеру (реестр 1inch)
    prices.js            — курсы + спарклайн для нативных монет (CoinGecko)
    swap.js                — котировки и обмен через ParaSwap
    onramp.js                — конфиг и URL для покупки за карту
    biometric.js               — WebAuthn/PRF биометрическая разблокировка
    crypto.js                   — шифрование seed-фразы (Web Crypto)
    storage.js                    — localStorage: vault + добавленные токены
    walletCore.js                   — деривация ключей, транзакции EVM/BTC
  components/
    Onboarding, BackupSeed, SetPassword, Unlock  — вход и первый запуск
    Dashboard, AssetDetail, AddAssetSheet          — список активов и детали
    SendSheet, ReceiveSheet, Sparkline               — переводы и графики
    SwapView, BuyView, BottomNav                       — обмен, покупка, навигация
    SettingsSheet, Toast                                 — настройки и уведомления
```
